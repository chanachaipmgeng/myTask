## สรุปสั้น

1. เปิด `http://127.0.0.1:4200/mockup` หรือเมนู **ระบบ → โหมดจำลอง**
2. กด **เปิดโหมดจำลอง** แล้ว **เล่นทั้งเรื่อง**
3. ดูผลที่คิว (MOCK-XL ค้าง), ปฏิทิน, ไปป์ไลน์, กระดานรายคน, แดชบอร์ดทีม (**6 ใบ · 6.5 MD**)
4. กด **ออกและคืนข้อมูลเดิม** เมื่อจบ

ไม่เขียนฐานข้อมูล และไม่ยิง myProject / mygit จริง
