- P6 ครบ (Syncfusion Tailwind 3 Theming, Sticky Sidebar & UX/UI Polish): ปรับใช้มาตรฐาน Syncfusion Tailwind 3 Dark Theme ครบทั้ง 20 หน้าจอ พร้อมผูก `theme="Tailwind3Dark"` บน Canvas/SVG 30 คอมโพเนนต์ · ปรับโครงสร้าง Sticky Fixed Sidebar (100vh) แก้ปัญหาเมนูเลื่อนหลุดจอเวลาหน้ายาว · เพิ่ม Desktop Mini-Sidebar 68px/260px · เพิ่ม Search Filter ใน Alert Dialog · เพิ่ม Previous/Next Person 1-on-1 Continuous Navigation บน `/people/:id` · เพิ่ม Activity & Delivery Log ใน Kanban Card Edit Dialog · เปิด Grid State Persistence (`[enablePersistence]="true"`) ในตารางหลัก · เพิ่ม Snapshot Deduplication Warning บน `/team`  
- P7 ครบ (Dual Theming - Light Mode & Dark Mode Support): เพิ่มระบบสลับธีม Dark Mode / Light Mode แบบ zero-reload ผ่าน `ThemeService` และปุ่มสลับธีมบน AppBar (`#appbar-theme-toggle`) · สลับ stylesheet อัตโนมัติระหว่าง `assets/themes/tailwind3.css` และ `assets/themes/tailwind3-dark.css` พร้อมสลับคลาส `e-dark-mode` / `e-light-mode` บน `document.body` · จดจำค่าที่เลือกใน `localStorage.getItem('md-theme')` พร้อม inline script ใน `index.html` ป้องกัน FOUC · ผูกธีมของกราฟและ ProgressBar 30 ตัวแบบ Dynamic ผ่าน `[theme]="theme.sfTheme()"` (`'Tailwind3Dark'` vs `'Tailwind3'`) · ตรึงพื้นหลังคอลัมน์ Opaque (`#ffffff` ใน Light Mode, `#0f172a` ใน Dark Mode) ของ Syncfusion Frozen Columns ไม่ให้ข้อความทะลุซ้อนทับกัน  
- P8 ครบ (Enterprise Multi-Team UI Screens 21–25 & Cross-Team SLA): เพิ่ม 5 หน้าจอระดับองค์กรรองรับ 6 สายงาน (RND, IMP, QA, UXBA, SUP, INFRA) ได้แก่ `/work/handoff` (ตรวจจับคอขวดข้ามทีม กราฟ Stage Aging แนวนอน Blocker Matrix และปุ่ม Ping Teams), `/quality/audit` (DoD Gate Verifier ตรวจ MR/Unit Test/Staging พร้อม One-Click Reject และวิเคราะห์ Reopen Root-Causes), `/analytics/time-audit` (ตาราง 3-Way Time Matching เปรียบเทียบ Estimate vs OP Actual vs GitLab Commit Span), `/tickets/disputes` (Split View รายการคำขอ พร้อมแบบจำลองคะแนน Projected Score Diff และ Audit Trail), และ `/admin/snapshot-check` (เช็คลิสต์ 4 ด่าน แถบความพร้อม Readiness % และตาราง Snapshot Preview Diff เปรียบเทียบดัชนีรายบุคคลก่อน Freeze)
- P9 ครบ (MD Mandate & Auto-Shift Workflow, Tiered Tolerance & Complete 25-Screen Manual): เพิ่มโฟลว์รับมืองานสั่งตรงจาก MD แบบครบวงจร: ตรวจจับ Active WIP อัตโนมัติเมื่อย้ายเข้า `In Progress`, Popup ถามพักงานและเลื่อนวันส่งแรก (`firstDueOn`) ด้วย `addWorkingDays` ข้ามวันเสาร์-อาทิตย์, เพิ่มปุ่ม `⚡ รับงานด่วน MD & เลื่อนงานเดิม` ใน `/queue`, เพิ่ม Checkbox และ `ejs-multiselect` ใน Kanban Dialog, คุ้มครองคะแนนงานที่พัก (การันตี 40 On-time, หักลบ `pausedDays` ออกจาก Actual MD การันตี 20 Accuracy), ป้องกันการเขียนทับ `firstDueOn` จาก OpenProject, ซิงก์ Reviewers & ApprovedBy จาก GitLab API v4 มอบเครดิต Peer Review Quota (10-15%), คำนวณความแม่นยำด้วย Tiered Tolerance (XS/S, M, L/XL), เพิ่มกราฟแท่งซ้อน Planned vs Unplanned vs MD Mandate บน `/team` และ `/people/:id`, แคปภาพหน้าจอจริงครบทั้ง 25 หน้าจอลงใน `docs/manual_assets/`, และสร้างเอกสารคู่มือฉบับสมบูรณ์ 25 หน้าจอทั้ง PDF และ HTML (`docs/คู่มือการใช้งานระบบ.pdf` / `docs/user-manual.pdf`)
